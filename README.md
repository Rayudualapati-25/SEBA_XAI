# SEBA-XAI Blockchain Implementations

This repository contains the completed SEBA-XAI access-governance implementations.
All demonstration data is synthetic.

## Projects

- [Permissioned Hyperledger Fabric implementation](seba_fabric_workspace/crime-records-network/README.md) — a multi-organization crime-records access network with on-chain policy evaluation, endorsement, auditing, and a web interface.
- [Solidity/Ethereum implementation](seba_fabric_workspace/seba-ethereum/README.md) — an EVM port of the access-governance contracts, with Hardhat tests and deployment scripts.

Each project is self-contained and includes its own setup, execution, and testing instructions.
