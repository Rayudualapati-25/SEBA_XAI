\title{SEBA-XAI: Explainable Policy-Aware Audit for Secure Inter-Agency Police Data Access Governance}

\author{Alapati~Venkat~Rayudu}

\maketitle

\begin{abstract}
Inter-agency police data sharing is not only a database-sharing problem.
Sensitive record access needs contextual authorization, tamper-evident audit,
and explanations that can be reviewed later. This paper proposes SEBA-XAI, an
application-layer access-governance and audit overlay for CCTNS/ICJS-compatible
police record workflows. Blockchain is used because multiple agencies may need a
shared tamper-evident audit trail without copying raw records into one central
database. The system keeps sensitive records off-chain and combines an
ABAC-based policy service, permissioned ledger-backed audit records, and an
explainable decision service for \emph{allow}, \emph{deny}, and
\emph{escalate} requests. The paper also studies a post-decision corruption
case: a compromised component changes the recorded policy decision and re-signs
the event, so the audit log still appears cryptographically valid. Because real
police access logs are not public, the evaluation uses a reproducible synthetic
workload. The results show that integrity-only audit baselines detect ordinary
tampering but miss the validly re-signed corruption case. In the same benchmark,
NS-PI drift detection and a trusted raw-attribute policy oracle detect that case
under different visibility assumptions. These findings support a scoped
prototype claim: access control, blockchain audit, and explainable review
artifacts address different failure modes and should be evaluated together.
\end{abstract}

\begin{IEEEkeywords}
Access control, blockchain audit, explainable AI, police data governance,
