# Sources

This folder contains source-tracking material for the research project.

Tracked files:

- `source_log.md`
- `literature_matrix.md`
- `dataset_inventory.md`

Local-only folders:

- `downloaded_research_papers_2026-05-29/`
- `reference_papers/`

The local-only folders contain downloaded PDFs and reference copies. They are
kept outside Git to avoid a large repository and to keep the GitHub repo focused
on reproducible source code, result tables, paper source, and citation/source
metadata.
