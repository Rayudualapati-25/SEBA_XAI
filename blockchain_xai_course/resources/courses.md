# Top Web Courses — Curated, Ranked, with Notes

This is the synthesis we used to design this entire syllabus. If you want to **supplement** a particular module, jump to a course matching it.

## Blockchain — top free/online courses

### Foundational

| Course | Provider | Why |
|---|---|---|
| **Bitcoin and Cryptocurrency Technologies** | Princeton (Coursera + book) | The single best deep dive into Bitcoin. Free textbook. Narayanan, Bonneau, Felten, Miller, Goldfeder. |
| **MIT 15.S08 — Blockchain and Money** | MIT OCW | Gary Gensler's lectures. Business + tech + policy. |
| **CS251 — Cryptocurrencies and Blockchain Technologies** | Stanford | Dan Boneh. Strongest crypto-focused syllabus. |
| **Berkeley CS294-164 — Blockchain Technology** | Berkeley | Research seminar; reading list is gold. |
| **Coursera Blockchain Specialization** | University at Buffalo | Hands-on Solidity + Truffle. |

### Smart contracts / Ethereum

| Course | Provider | Why |
|---|---|---|
| **CryptoZombies** | Loom Network | Best Solidity onboarding game. |
| **Patrick Collins — Smart Contract Developer (Cyfrin / Updraft)** | YouTube + cyfrin.io | The de facto modern Solidity bootcamp. Free. |
| **Alchemy University** | Alchemy | Modules across Ethereum dev, security, ZK. |
| **ConsenSys Academy Bootcamp** | ConsenSys | Career-track, in-depth, paid. |
| **Speedrun Ethereum** | Scaffold-ETH (BuidlGuidl) | Project-based mastery; do all challenges. |

### Zero-Knowledge

| Course | Provider | Why |
|---|---|---|

| **0xPARC ZK Learning** | 0xPARC | Hands-on Circom, applications |
| **Programming ZK Apps with Noir** | Aztec | Modern, friendly |
| **RareSkills ZK Bootcamp** | RareSkills | Paid, well-regarded |

## XAI — top free/online courses

### Foundational

| Course | Provider | Why |
|---|---|---|
| **Interpretable Machine Learning** | Christoph Molnar (book, free online) | **The** canonical XAI textbook. Read cover-to-cover. |
| **Kaggle — Machine Learning Explainability** | Kaggle | 4-hour micro-course; hands-on SHAP/PDP/permutation |
| **DeepLearning.AI — AI Explainability** short courses | DLAI | Modular; recent additions on LLM interp |
| **Stanford CS329T — Trustworthy ML** | Stanford | Includes XAI, fairness, robustness |
| **Harvard CS282BR — Topics in Interpretability** | Harvard | Research-style; readings are excellent |
| **CMU 10-718 — Machine Learning in Practice** | CMU | Practical XAI modules |

### Mechanistic interpretability (the hot frontier)

| Course | Provider | Why |
|---|---|---|
| **Neel Nanda — Mechanistic Interpretability Quickstart Guide** | neelnanda.io | The single-best entry point. Free. |
| **ARENA (Alignment Research Engineer Accelerator)** | LessWrong / Apollo Research | 6-week intensive; TransformerLens + IOI + SAEs |
| **MATS (ML Alignment & Theory Scholars)** | MATS Program | Selective; produces frontier researchers |
| **Anthropic Transformer Circuits Thread** | Anthropic | Living research blog; foundational reading |
| **Distill.pub Circuits Thread** | Distill (archived) | Visual classics — start here |

### Causal / counterfactual XAI

| Course | Provider | Why |
|---|---|---|
| **Causal Inference for The Brave and True** | Matheus Facure (free book) | Best practical primer |
| **Brady Neal — Introduction to Causal Inference** | bradyneal.com | Video course |
| **Pearl, Glymour, Jewell — Causal Inference in Statistics: A Primer** | Wiley book | Definitive |

### Fairness / FAccT

| Course | Provider | Why |
|---|---|---|
| **Berkeley CS294 — Fairness in ML** | Berkeley | Solid academic intro |
| **FairLearn / AI Fairness 360 docs** | Microsoft / IBM | Tool-grounded |
| **fairmlbook.org** | Barocas, Hardt, Narayanan | The textbook |

### Domain-specific XAI

| Course | Provider | Why |
|---|---|---|
| **MITx 6.S897 — ML for Healthcare** | MIT | Includes clinical XAI sections |
| **Coursera AI for Medicine Specialization** | DLAI / Pranav Rajpurkar | Practical, vision-heavy |
| **FAccT workshops & tutorials** | annual | Best venue to learn FAccT-flavor XAI |
